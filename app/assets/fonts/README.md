# Libre Franklin web fonts

Unmodified Google Fonts v20 WOFF2 Latin and Latin Extended variable subsets,
downloaded September 6, 2026. These replace the external Google Fonts stylesheet.
The site declares weights 300 through 600 and preloads only the Latin subset.
Libre Franklin is distributed under the included SIL Open Font License.

Source stylesheet: https://fonts.googleapis.com/css2?family=Libre+Franklin:wght@300..600&display=swap
Latin: https://fonts.gstatic.com/s/librefranklin/v20/jizDREVItHgc8qDIbSTKq4XkRiUf2zc.woff2
Latin Extended: https://fonts.gstatic.com/s/librefranklin/v20/jizDREVItHgc8qDIbSTKq4XkRiUR2zcLig.woff2
